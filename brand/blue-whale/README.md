## 品牌色（取自本隊徽，已定案）

客戶指示**配色一律依隊徽取樣，不自行配色**。主色與深色是隊徽上的實際用色，其餘四個由主色依對比度需求推導。
定案值同時寫在藍鯨規劃書 §8.1 與 [`../../docs/06-conventions.md`](../../docs/06-conventions.md) §2，**三處必須一致**。

| Token | 值 | 來源 | 對比度 |
|---|---|---|---|
| `--brand` | `#2196D5` | **隊徽藍**，佔隊徽藍色像素的 92.8%（眾數） | 對白 3.29:1 — 大字 AA ✅／小字 ✗ |
| `--brand-aa` | `#1A78AA` | 主色降亮度 20% | 對白 **4.87:1** ✅ |
| `--brand-bright` | `#50B0E4` | 主色提亮 25% | 對 `--ink` 8.63:1 |
| `--brand-deep` | `#156088` | 主色降亮度 36% | 白字 6.86:1 |
| `--ink` | `#040000` | **隊徽黑**，鯨魚與字體的實際用色 | 對白 20.89:1 |
| `--ink-2` | `#1D1919` | `--ink` 提亮一階 | 對白 17.42:1 |
| `--ink-trim` | `#040000` | 同 `--ink` | — |

隊徽上另有兩個中性色：盾牌描邊 `#5D5B5B`、投影 `#DADBDB`。**它們是隊徽內部的造型用色，不進 design tokens。**

### 取樣方法（要重驗時照這個做）

放大取樣會受插值影響，所以一律在**不透明像素**上取眾數，不取平均：

```python
from PIL import Image
from collections import Counter
im = Image.open('bw-crest.png').convert('RGBA').resize((900, 885), Image.LANCZOS)
px = [p for p in im.getdata() if p[3] > 250]
blues = Counter(p[:3] for p in px if p[2] > 140 and p[2] - p[0] > 40)
print(blues.most_common(3))   # → (33, 150, 213) = #2196D5
```
