## 1. 多語系

| 項目 | 規則 |
|---|---|
| 語系 | **繁體中文（預設）／英文**；日文列為後續評估，**不實作但架構須預留** |
| URL | `/zh/…`、`/en/…` 獨立網址 |
| hreflang | `zh-Hant`、`en`、**加上 `x-default`** |
| Fallback | 未翻譯內容顯示繁中，並標示「本頁尚無此語系版本」（fallback 或隱藏可於後台設定） |
| 切換行為 | 停留於當前頁的對應語系版本，不要跳回首頁 |
| 擴充 | 新增語系不需改程式 |

**英文版優先範圍**（Phase 2 上線時的順序）：
首頁 → 02 關於磐石 → 03.4 國際發展通道 → 04 學院 → 09 合作與贊助 → 10 聯絡表單 → 12 FAQ → 13 賽事行事曆

**後台支援**（I 模組）：翻譯狀態總覽矩陣（可篩「缺英文」）、字串翻譯表（按鈕／表單標籤／提示／錯誤訊息）、日期與數字格式、字型設定。
**權限**：翻譯人員角色只能編輯 `en` 欄位，不能改繁中原文與發布狀態。

## 2. SEO 九項基礎

| 基礎 | 實作方式 |
|---|---|
| 清晰的架構與層級 | URL 直接對應網站層級，如 `/zh/academy/join/` |
| 關鍵字導向內容 | 每頁可設主要關鍵字，提供標題／H1／首段的使用檢查 |
| 結構化資料 | Organization、SportsTeam、SportsEvent、Event、Person、Article、Course、FAQPage、BreadcrumbList。**Product Schema 由 Shopify 端負責，本站不輸出** |
| 內部連結 | 文章關聯球員／球隊／課程並自動產生互連區塊；**孤立頁面偵測** |
| 行動友善 | Mobile First、觸控目標 ≥ 44px、行動版 CTA Bar |
| 載入速度 | 圖片 WebP／lazy load、CDN、關鍵 CSS 內聯；**LCP < 2.5s、CLS < 0.1、INP < 200ms** |
| 高品質原創內容 | 球員故事、比賽報導、漫畫、**慈善事蹟**為差異化資產 |
| 定期更新 | 排程發布 + 內容行事曆檢視 |
| 多語系 | 見上節 |

## 3. GEO（生成式引擎最佳化）

- **獨立 FAQ 單元（12）是 GEO 核心資產**——問答格式最易被 AI 引擎擷取引用，**FAQPage Schema 必須完整輸出**
- 每頁提供結構清楚的 H2/H3 與 FAQ 區塊，利於 AI 摘錄
- 重要事實（成立年份、梯隊、場地、聯絡方式、慈善成果數據）**以結構化資料與明確文字雙重呈現**
- 維護 `llms.txt` 描述站點內容重點與授權範圍

## 4. 非功能性需求

| 面向 | 需求 |
|---|---|
| 效能 | 首頁 LCP < 2.5s（4G）、Lighthouse Performance ≥ 85 |
| 相容性 | Chrome / Safari / Edge / Firefox 最新兩版；iOS 15+、Android 10+ |
| 無障礙 | **WCAG 2.1 AA** |
| 安全 | HTTPS 強制、後台 2FA、CSRF／XSS／SQL Injection 防護、上傳類型與大小限制、後台 IP 白名單（選配）；會員系統另需密碼雜湊、Session 逾時、登入失敗鎖定、防暴力破解 |
| 個資 | 報名／詢問／會員資料（含 LINE 綁定識別碼）加密儲存、保存期限政策、當事人刪除請求流程；**未成年學員資料須取得監護人同意** |
| 可用性 | 99.5% 上線率；每日備份、異地保存 30 天 |
| 擴充性 | 新增年齡層／賽季／課程類型／語系**不需改程式**；女足日後升級可直接沿用球隊模組 |
| 監控 | 錯誤追蹤（Sentry 類）、Uptime 監控、**表單送出失敗告警** |

## 5. 舊站遷移

- 既有官網 www.tcrfc.tw 上線時**全站 301 轉址**至新站對應頁，保留 SEO 權重（後台 H 模組支援批次匯入對照表）
- 內容遷移原則：先盤點分類（保留／改寫／捨棄），**只遷移仍具時效與品質的內容**
- 新聞類建議保留近 **1–2 年**；過舊內容不逐篇搬移，但**網址仍要轉址**
