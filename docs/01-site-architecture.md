規模：**13 大單元、約 60+ 子頁面、7 類 CTA 表單、雙語系**。

## 2. 頁面型態（決定用哪種後台管理方式）

| 型態 | 範例 | 後台管理 |
|---|---|---|
| 主頁 Main Page | 首頁 | 版位模組化編排（Page Builder），對應後台 B4 |
| 主分類 Landing | 各單元首頁 | 固定版型 + 可編輯區塊（B1） |
| 子頁 Sub Page | 2.1、3.1、11.1… | 固定版型 + 可編輯區塊（B1） |
| 內容／項目頁 | 球員、教練、新聞、賽事、商品、漫畫集數 | 資料型 CRUD（列表 + 詳情） |
| CTA 頁 | 10.x 各表單、贊助提案下載 | 表單設計器 + 收件管理（G1/G2） |

> **判斷法則**：這一頁的內容會不斷長出新的一筆嗎？會 → 資料型 CRUD；不會 → 靜態頁區塊編輯。
> 女足（06）雖然是整個單元，但屬**靜態頁**。

## 3. 全域導覽

**主選單（Desktop）**
`ABOUT / CLUB / ACADEMY / PROGRAMS / WOMEN'S / SCHEDULE / NEWS / CULTURE / PARTNERS / CHARITY`
右側常駐：`JOIN 加入我們`（強調色按鈕）、`會員登入 / 會員中心`、語系切換 `繁中 / EN`

- **Mega Menu**：主分類展開第二層 + 一張主視覺圖 + 一個該分類主 CTA。**女足與慈善為單層，直接連結不展開。**
- **行動版**：漢堡選單全屏抽屜（含語系與會員入口）＋ 底部固定 CTA Bar（`加入球隊` / `聯絡我們`）
- **Footer**：站點地圖四欄（含 FAQ、慈善）、社群連結、贊助夥伴 Logo 輪播、Shopify 商店連結、聯絡資訊、隱私權／Cookie 政策、語系切換

## 4. 全站共用功能 G-01 ~ G-12

| 代號 | 功能 | 要點 |
|---|---|---|
| G-01 | 多語系切換 | `/zh/`、`/en/`；未翻譯 fallback 繁中並標示；切換時停留當前頁；**預留第三語系** |
| G-02 | 全站搜尋 | 跨新聞／球員／教練／課程／FAQ／慈善事蹟，關鍵字高亮 + 分類篩選 |
| G-03 | 麵包屑 | 同時輸出 BreadcrumbList Schema |
| G-04 | 響應式 | Mobile First，斷點 **360 / 768 / 1024 / 1440** |
| G-05 | CTA 元件庫 | 通用轉換區塊（報名／詢問／下載），可掛任何頁面底部 |
| G-06 | 社群分享 | Facebook / Instagram / LINE / X / 複製連結 |
| G-07 | Cookie 同意 | GDPR 友善，**追蹤碼須於同意後才載入** |
| G-08 | 無障礙 | WCAG 2.1 AA、鍵盤操作、alt、對比度 |
| G-09 | 電子報訂閱 | Footer 常駐，串接 EDM |
| G-10 | 404 / 維護頁 | 品牌化，附熱門連結導流 |
| G-11 | 會員登入狀態列 | Header 顯示登入／註冊或會員選單（會員卡／會籍／登出）；支援 LINE 一鍵登入。**不做表單自動帶入** |
| G-12 | FAQ 快捷區塊 | 可掛任何頁面底部，依主題自動撈 FAQ |

> G-05 與 G-12 是**可複用元件**，實作時應設計成能掛載於任意頁面底部的區塊，不要各頁重寫。

## 5. URL 規則

| 規則 | 範例 |
|---|---|
| URL 直接對應網站層級 | `/zh/academy/join/` |
| 語系前綴 | `/zh/…`、`/en/…`，`hreflang` 含 `x-default` |
| 行事曆隊別分類（可索引） | `/schedule/d1/`、`/schedule/u15/`、`/schedule/u14/`、`/schedule/u12/` |
| 重要賽事獨立網址 | `/schedule/2026-03-15-tcrfc-vs-xxx` |
| FAQ 單題深層連結 | `/faq/#q-123` |
| 舊站轉址 | www.tcrfc.tw 既有網址 301 至新站對應頁（後台 H 模組批次匯入） |
