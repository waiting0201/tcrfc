## 2. 已定案前提

| 項目 | 決議 |
|---|---|
| 技術選型 | **暫不討論**，規劃書僅定義功能需求 |
| 金流與購物 | **本站**不做站內電商，購物一律轉往 **Shopify**。此前提**只適用於本站**，慈善捐款平台正式串接 LINE Pay |
| 語系 | 繁中（預設）／英文；日文不在本次範圍，架構預留 |
| 會員系統 | **需要**，納入 Phase 2。收斂為**會籍**一件事：免費與付費兩層，會員享特約店家折扣，付費會員另獲球衣。管道為 Email + LINE 一鍵登入（**不用 Google**） |
| 會員系統不做的事 | ✗ 點數 ✗ 電子錢包 ✗ 票務與門票套票 ✗ **店家掃碼核銷與報表** ✗ Shopify SSO ✗ 報名歸戶與表單自動帶入 ✗ 學員家長綁定 ✗ 通知中心與 LINE 推播 |
| 會籍計期 | **球季制**（如 2026/27），全體同時到期，續會集中於球季末 |
| 會費收款 | **LINE Pay**（收款連結／官方帳號帳單）與現場收款；官網不接金流，後台核對後開通 |
| 折扣使用方式 | 到店**出示電子會員卡**目視即可；QR 指向公開唯讀驗證頁，**不核銷、不計次、店家不需系統** |
| LINE 官方帳號 | **已有帳號**，直接串接既有帳號；本站僅用於登入與綁定 |
| 會員優惠 | 特約店家折扣由本站 8.4 維護；Shopify 商店優惠一律以**發送折扣碼**處理，不做帳號串接 |
| 球迷捐款 | **移至獨立的慈善捐款平台**（獨立網域、共用本站後台與資料庫、串接 LINE Pay 與電子發票）。本站 11 章只做介紹與導流 |
| 志工報名 | **不做**。11 章 CTA 由三種收斂為兩種；有需求改以一般聯絡表單（10.7）承接 |
| FAQ | 獨立單元 12，集中管理、跨頁嵌入 |
| 慈善事蹟 | 每筆提供**團體名稱、捐助內容、活動圖片**三項核心資料 |
| 女子足球 | 單頁介紹 + 導流女足官網，本站不維護名單與賽程 |
| 賽事資料 | **全部人工維護**，不串接外部 API；提供 CSV 批次匯入 |
| 行事曆 | **以比賽為核心**；學院課程、營隊、專項訓練不納入。內容需中英雙語 |
| 台中磐石漫畫 | **全部免費公開**，不設付費牆、不需登入 |
| 品牌色基準 | **以 [`../reference/TCR_logo_CMYK.ai`](../reference/TCR_logo_CMYK.ai) 為唯一真實來源**（2026-08-17 定案） |

## 3. 待確認事項（16 項）

**擋開發的（優先問）**

1. **Shopify 商店網址** — 08.3 商品櫥窗導流目標；若未開站需確認預計上線時間（捐款品項已移出本站範圍）
2. **既有官網內容遷移範圍** — www.tcrfc.tw 哪些保留／改寫／捨棄（新聞類建議留近 1–2 年）
3. **特約店家首波名單** — 本站不做票務，付費會籍的價值全靠**店家折扣與球衣**，首波名單的數量與品質**直接決定付費層能否成立**，須於上線前談定
4. **年費金額與方案設計** — 單人方案費用？是否設家庭方案（1 成人 + N 小童）？各含幾件球衣？

**影響規格細節**

5. **球季起訖日與季中入會計價** — 會籍以球季計期，需確認球季起訖，以及季中入會是否按比例折價
6. **會費的 LINE Pay 收款形式** — **會籍會費**採收款連結／官方帳號帳單（本站預設，不碰金流），或比照慈善站改走 LINE Pay API？慈善站**已定案正式串接**，商家帳號完成後會費要不要沿用可另評估
7. **會員編號格式** — 建議 `TCR-<球季>-<流水號>`
8. **球衣尺碼表與備貨量** — 提供的尺碼範圍（成人／童裝）與依尺寸的備貨策略
9. **捐款收據與勸募資格** — 已於慈善捐款平台規劃書 §5 規範（電子發票與捐贈收據兩種，依項目設定）。**勸募資格屬該平台的上線前提**，須由俱樂部與會計師／法務確認
10. **英文版內容產出方式** — 俱樂部提供／委外翻譯／先上重點頁面？**影響 Phase 2 時程**
11. **慈善金額是否公開** — 預設不公開，是否有需公開的個案？
12. **試訓是否顯示於行事曆** — 預設關閉，可於後台開啟
13. **賽事購票與轉播資訊** — 是否有售票管道或轉播平台需顯示於賽事卡片
14. **漫畫更新頻率** — 影響「最新集數」與首頁曝光規劃
15. **個資保存期限** — 規劃書要求七類表單顯示保存期限說明，但未定實際年限。**法遵項目，擋表單上線**，須由俱樂部與法務確認
16. **16px 簡化版隊徽** — 隊徽翅膀線在 16px favicon 會糊成色塊。現代瀏覽器優先取 SVG／32px，影響有限；若在意需請設計方提供簡化版。**本專案不自行改動標誌造型**（見 [`../brand/README.md`](../brand/README.md) §2）

**規劃書未列、但實務上必須決定的**

- **技術選型**：規劃書明確排除，但內容套版前必須定案，否則改寫產物可能要轉兩次格式（見 [`07-content-pipeline.md`](07-content-pipeline.md) 階段四）
- **正式站的部署環境與網域切換方式**：現有 mockup 已部署於 Cloudflare Pages（專案 `tcrfc-mockup`，全站 `noindex`）
