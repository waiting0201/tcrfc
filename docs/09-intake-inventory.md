## 2. 阻塞項：113 個 `.gdoc` / `.gsheet` 無法讀取

客戶把文稿放在 Google Drive，同步下來的是 **185 bytes 的捷徑檔**，只含 `doc_id`，不含任何內文：

```json
{"":"警告！請勿編輯這個檔案！...","doc_id":"1BRbwyf...","resource_key":"","email":"tim@weypro.com"}
```

| 類型 | 數量 |
|---|---|
| `.gdoc`（Google 文件） | 107 |
| `.gsheet`（Google 試算表） | 6 |
| **合計** | **113** |

分布：07 新聞 83、02 關於 11、03 一線隊 7、11 慈善 5、05 課程 4、08 文化 3、04 學院 2、10 聯絡 2、00 品牌 1、12 FAQ 1。

### 三個解法（擇一）

1. **修 Drive 連接器權限（最省事）** — 目前連接器已連線但 scope 不足，讀取一律回
   `Insufficient scope: required .../auth/drive.readonly`。
   到 claude.ai → 設定 → 連接器 → Google Drive 重新授權並勾選雲端硬碟讀取權限，
   之後可依 `doc_id` 直接批次抓全部 113 篇。
2. **請客戶批次匯出** — Drive 上選取資料夾 →「下載」，Google 會自動把 Docs 轉成 `.docx`、
   Sheets 轉成 `.xlsx` 一併打包。這是對客戶最無痛的方式（一個動作）。
3. **本機 Drive 掛載** — 已確認**行不通**：`~/Library/CloudStorage/GoogleDrive-tim@weypro.com`
   底下沒有這份收件夾（客戶端共用資料夾，未同步到本機），且 Drive for Desktop 對 Google 原生格式
   一樣只放捷徑檔。

> 客戶提供的 Drive 資料夾：`https://drive.google.com/drive/u/1/folders/1lAHoabSnw4FKsqWpOxB_xmJahSjZXXJn`
> （注意是 `/u/1/`，第二個 Google 帳號 — 重新授權時要確認連的是同一個帳號。）
