## 4. 紀律（本目錄的既有規則，續做時請沿用）

1. **逐字保留原文**。錯字、全形半形混用、前後矛盾之處一律照抄，不改寫、不潤稿、不補完。
   有明顯矛盾的地方另以 `> ⚠️` 註記，但**不動原文**。
2. **不下載圖片**。只記錄圖片網址與圖說。舊站圖片含未成年學員與球員肖像，
   且本 repo 是公開的（CLAUDE.md 全域規定第 7 條）。
3. 球員名單照實記錄（舊站已公開資訊），**不額外蒐集或推測任何個資**。
4. 抓不到就寫「本次未取得」，**不編造**。
