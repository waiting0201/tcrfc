# content/legal/ — 政策與條款母稿（2026-10-07 草擬）

Cookie 政策、隱私權政策、會員條款的**中英文母稿**，兩個俱樂部各一套（共 12 份）。

| 檔案 | 後台位置 | `settings` 鍵 |
|---|---|---|
| `{club}/cookie.{zh,en}.txt` | 網站設定 →「政策與條款」→ Cookie 政策 | `policy.cookie` |
| `{club}/privacy.{zh,en}.txt` | 同上 → 隱私權政策 | `policy.privacy` |
| `{club}/member-terms.{zh,en}.txt` | 同上 → 會員條款 | `policy.member_terms` |

`{club}` 是 `tcrfc`（台中磐石）或 `bw`（台中藍鯨），`zh` 存 `zh-Hant`、`en` 存 `en`。

## 格式

- **純文字、以空行分段**。前台以文字節點輸出（`usePolicy`，不得用 v-html），所以這裡**不寫 Markdown**。
- 標題就是獨立的一段，例如「一、適用範圍」。網址只會顯示成文字，不會變成連結。
- **本機開發庫**：`db/seed/backoffice_seed.py` 區段 60 會讀取本目錄，種進 `policy.*`（冪等，已有內容就不覆寫）。這段刻意不進正式庫的內容種子，`db/prod/` 不受影響。
- **正式庫**：由後台「網站設定 → 政策與條款」貼上，不經種子腳本。
- 後台內容改了，回頭同步這裡的母稿；母稿改了，後台也要重新貼一次。

- 蒐集的欄位：會員、監護人、會籍與球衣、訂單、表單、電子報、抽獎扣繳
