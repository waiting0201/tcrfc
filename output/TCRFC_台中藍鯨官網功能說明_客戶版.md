## 1. 這個網站與磐石官網的關係

台中藍鯨有**自己的獨立網址、自己的前台網站、自己的品牌色與標誌**，中英雙語。

但它**與台中磐石官網共用同一套後台與同一個資料庫**——這是刻意的安排：

| | 分開的 | 共用的 |
|---|---|---|
| 網址 | ✔ 各自獨立 | |
| 前台網站 | ✔ 各自獨立 | |
| 品牌（標誌、色彩、文案署名） | ✔ 各自獨立 | |
| 球隊、球員、賽程、新聞 | ✔ 資料各自分開 | |
| 贊助商與合作夥伴 | ✔ **必須分區，不得混列** | |
| 後台入口與帳號 | | ✔ 同一個 |
| 會員帳號 | | ✔ 一個人一組帳號 |
| 商店與收款 | | ✔ 同一套（見第 3 節） |

**為什麼不各做一套？** 兩套後台代表兩套帳號、兩套維護流程、兩份學習成本；而藍鯨目前是由磐石的團隊在營運，同一個人要在兩邊之間切換。一套後台、資料分開，是維護成本最低的做法。

**登入後怎麼切換**：後台上方有站台切換器，選擇現在要操作磐石還是藍鯨，切換後所有清單只顯示那一隊的資料。

比照磐石官網的結構，**11 個單元**。編號刻意保留磐石的對應關係（跳過 06 與 11），這樣維護人員在後台切換站台時不會弄錯。

| **07** | **新聞中心** | 最新消息、賽事報導、人物故事 |
| **08** | **藍鯨文化 ＋ 商店** | 品牌故事、周邊商品 |

加上**會員中心**（登入後區域）。

**兩個單元刻意不設**：

| 磐石有、藍鯨沒有 | 為什麼 |
|---|---|
| **女子足球** | 這整個網站就是女足，不需要再有一個介紹女足的單元。磐石官網的那一頁，入口就是連到這個網站 |
| **慈善與社會影響** | 慈善捐款由台灣足球策略發展協會主辦，與藍鯨無關 |

**一個單元改了名**：磐石的「足球學院」在藍鯨改為「**青年隊**」——藍鯨既有的是 U15／U12 女子隊，不是磐石的學院招生體系，不沿用學院的課程與招生架構。

> ⚠️ **夥伴與贊助必須與磐石分區呈現，不得混列。** 兩隊的贊助合約是各自簽的，同一家公司同時贊助兩隊時，在兩站各自呈現。

## 3. 會籍與商店

### 會籍

**一個人一組帳號，但會籍是每個俱樂部各一份。** 藍鯨的球迷可以**只加入藍鯨**，不必連磐石一起加入——這是預期狀況，不是例外。

- 每一份會籍配**一張電子會員卡**，藍鯨的卡帶藍鯨的標誌與品牌色，藍鯨的合作店家看到的就是藍鯨的卡。
- 層級仍然只有免費與付費兩層，**不會因為多一支球隊就多一種會員身分**。
- **兩隊球季不同步**，到期日與續會提醒各自計算。

### 商店與收款

藍鯨的商品在同一套商店系統裡賣，但有一條必須講清楚的規則：

> **收款主體是台中磐石足球俱樂部。** 付款走俱樂部的 LINE Pay、發票抬頭是俱樂部，事後再依商品歸屬結算給藍鯨。

這是**代收代付**的安排，對客人沒有影響（結帳流程完全一樣），但對帳務有影響，所以在這裡寫明。購物車**一次只能買同一個俱樂部的商品**。

## 5. 誰能做什麼

後台採角色分工，實務上會用到六種（完整說明見磐石官網的功能說明）。與藍鯨直接相關的是其中一種：

### 合作球隊管理

專為藍鯨方的維護人員設計的角色：

| 能做 | 不能做 |
|---|---|
| 自家的新聞、頁面、FAQ | 看到磐石的任何內容編輯權 |
| 自家的球隊、球員、賽程、賽果 | 動磐石的球隊 |
| 自家的夥伴與贊助 | 看到磐石的贊助合約 |
| 自家的商品與訂單 | 執行退款、改金流設定 |
| **自家的會籍紀錄** | **看到磐石的任何會籍列** |
| 自家的表單與單頁 SEO | 發推播、管廣告、管系統 |

**會員個資另有一層保護**：即使是自家的會籍，**會員主檔的欄位（Email、電話、生日、地址）一律遮罩**。原因是會員帳號是一個人一組、跨兩隊共用，不能因為對方買了藍鯨會籍就讓另一邊看到完整個資。

> **這個角色可以先不指派任何人。** 藍鯨目前由磐石的團隊在維護，用自己既有的帳號即可；角色先建好放著，等藍鯨方要有自己的維護人員時再指派。

## 6. 品牌與視覺

藍鯨站沿用磐石官網的**版型系統**（卡片、切角、大型數字、色帶這些元件與品牌無關），**只替換品牌色與標誌**。

**品牌色一律取自隊徽**，不自行配色：

| | 值 | 用在哪 |
|---|---|---|
| **隊徽藍** | `#2196D5` | 色塊、大型標題 |
| **小字專用（深一階）** | `#1A78AA` | 白底小字、按鈕上的白字 |
| **隊徽黑** | `#040000` | 內文與深色底 |

> ⚠️ **小字不能直接用隊徽藍。** 隊徽藍在白底上的對比度不足以讓小字符合無障礙標準，所以小字一律改用深一階的版本。肉眼幾乎看不出差別，但這條線必須守。

**標誌**：使用隊徽的高解析去背原始圖檔，**網站、App 圖示與一般文件都足夠**。
**標誌一律使用既有隊徽原檔**——不自行畫標誌、不從網頁截圖描摹、不把小圖放大充數。

## 7. 上線後誰要持續維護什麼

| 要維護的東西 | 多久一次 | 不做會怎樣 |
|---|---|---|
| **賽程與賽果** | **賽季期間每週** | 賽事行事曆是這個網站的核心，資料一延遲就直接傷到 |
| **新聞** | 每週一到兩則 | 首頁會顯得停擺 |
| **球員與教練名單** | 每季，轉隊時隨時 | 名單過期比沒有名單更糟 |
| **賽事報名與聯絡收件** | 每日 | 詢問等不到回覆就流失 |
| **會籍開通與續會提醒** | 每日到每週 | **兩隊球季不同步，全年都會有到期案件** |
| **英文版** | 跟著中文版 | 英文版會逐漸落後 |

> **內容生產才是主要成本，不是網站開發。** 前台可以複製磐石的骨架，但沿革、球員簡介、賽事資料與英文翻譯不行——這些要人寫。

## 8. 雙語

- **繁體中文為主，英文為輔**，網址以 `/zh/`、`/en/` 區隔，規則與磐石官網相同。
- 所有前台看得到的內容都有中英兩個欄位，英文可以先留空，但欄位一定存在。
- 架構上已預留第三語系。
