## 1. 這個 App 要做什麼

### 1.1 一句話定位

**這個 App 不是官網的縮小版，也不是把網頁包進一個殼裡。**

如果只是把網站塞進 App，結果會是一個比網站慢、又要多花一份維護力氣的網站。所以我們替每一項功能設了一道門檻——**一項功能要進 App，至少要符合下面其中一項**：

| 標準 | 白話說明 | 例子 |
|---|---|---|
| **只有手機做得到** | 需要定位、離線、推播、行事曆、相機這類手機才有的能力 | 附近的特約店家、沒訊號也能出示的電子會員卡、開賽前提醒 |
| **內容已經在官網後台裡** | 沿用官網已經在維護的內容，不需要另外產出一份新的東西就能上線 | 賽程、最新消息、球員名單、課程梯次 |

兩項都不符合的功能，一律不放進 App。

### 1.2 三個前提，決定了整個 App 的樣子

| 前提 | 帶來的結果 |
|---|---|
| **App 和官網用同一套後台** | 內容只維護一次。同仁在官網後台改賽程、發新聞、調整店家優惠，App 立刻同步。**不會多出第二套要維護的後台** |
| **會員會在球場、在店家櫃檯用它** | 現場常常沒訊號。所以**電子會員卡、已下載的賽程、看過的新聞，沒有網路也要能用** |
| **廣告是自己賣的，不是接聯播網** | 版位賣給在地商家，成效由自家系統實際量測。不追蹤使用者、不看瀏覽紀錄投放，數字是誠實的，也能直接拿給廣告主看 |

### 1.3 和官網、慈善捐款平台的關係

| | 承接什麼 | 收款主體 |
|---|---|---|
| **官方網站** | 對外內容與搜尋引擎的主體、線上商店、完整後台 | 俱樂部 |
| **慈善捐款平台** | 合作店家掃碼捐款、發票與收據、分潤結算 | **台灣足球策略發展協會** |
| **行動 App**（本文件） | 會員隨身介面、賽事資訊、附近店家、自售廣告 | 俱樂部 |

三者共用同一套後台與同一份資料，但**主體與金流帳戶完全分開**：App 收的是俱樂部的會費，慈善平台收的是協會的捐款，兩者不共用商店帳號，也不會互相混淆。

## 2. 打開 App 會看到什麼

底部固定五個分頁，任何功能最多點三層就到得了。

| 分頁 | 裡面有什麼 |
|---|---|
| **首頁** | 下一場比賽倒數、最新消息、附近店家、廣告版位、贊助商 Logo 牆 |
| **賽程** | 各隊分頁、賽程與賽果切換、單場詳情 |
| **會員** | 電子會員卡、會籍狀態、我的報名、球衣登記、抽獎資格 |
| **新聞** | 分類列表、內文、離線閱讀 |
| **更多** | 球隊名單、特約店家、課程報名、夥伴與贊助商、慈善（外連）、商店（連往官網商店）、常見問題、設定 |

**一個重要的設計決定**：**沒有登入的人也要能完整看完賽程、新聞、球隊、特約店家和課程。**

登入牆只擋在四個地方：**電子會員卡、我的報名、續會付款、抽獎資格**。

特約店家清單本身是公開的——它正是讓人願意加入會員的主要誘因，把它鎖起來等於把轉換的門關上。清單上只用標籤標示「全會員適用」或「限付費會員」，讓人知道哪些優惠要付費會籍才拿得到。

## 3. 功能清單

### 3.1 賽事與賽果

| 功能 | 說明 |
|---|---|
| 各隊賽程 | 一線隊、U15、U14、U12 分頁瀏覽。日後要加 U18 或 U10，後台新增一支球隊即可，**App 不用改版重上架** |
| 賽程／賽果切換 | 未開打的看賽程，打完的看比分 |
| 篩選 | 賽事類型（聯賽／盃賽／友誼）、主客場 |
| 單場詳情 | 日期時間、對手、場地、輪次；打完後加上比分、進球者與時間、卡牌、出賽名單、賽後報導連結 |
| **加入手機行事曆** | 單場加入，或整季一次匯入到手機原生行事曆 |
| **場地導航** | 一按開啟手機地圖，直接導航到球場 |
| **開賽提醒** | 開賽前 2 小時推播提醒，只推給有訂閱該隊的人，可自行關閉 |
| **場地確定通知** | 場地原本是「待定」、後來確認時，自動通知關心那支球隊的人 |
| 離線可看 | 賽程與賽果下載過就能離線查閱 |

**幾點說明**

- 對外顯示一律寫「**一線隊 / First Team**」，全站只有這一支一隊。
- **不做即時比分自動更新**。賽事資料是人工維護的，做不到真正的「即時」，硬做只會失信於使用者。
- App 的篩選比網頁少一層，是**刻意的**。官網賽程頁有五組篩選同時排在畫面上，手機寬度撐不住，硬塞會變成沒人用的介面。

### 3.2 電子會員卡

**這是付費會員在店家櫃檯感受最直接的一項功能。**

| 功能 | 說明 |
|---|---|
| App 內會員卡 | 卡面有會員編號、QR Code、姓名、會籍層級、有效期限 |
| **離線可出示** | **沒訊號也能秀卡**——球場地下室、店家櫃檯常常收不到訊號，這是網頁做不到的一件事。卡面會標示「最後同步時間」，太久沒連網會提醒 |
| 自動更新 | 續約或升級層級之後，卡面資訊自動更新，會員什麼都不用做 |
| 卡片作廢 | 手機遺失時可自行重新產生 QR，舊的立刻失效 |
| 快速開啟 | 可用指紋或臉部辨識直接叫出會員卡 |

**店家怎麼驗卡**：店員**目視看卡**，或用手機掃 QR 開啟一個公開驗證頁，上面只顯示姓名首字、會員編號、層級、有效或已過期。

**不做掃碼核銷**：不記次、不出店家報表、店家不需要開帳號、不用另外裝任何東西。這是刻意的取捨——一旦做核銷，就要替每一家店開帳號、做報表、處理對帳，等於長出第二套系統。

### 3.3 特約店家與附近地圖

**這是 App 相對於網站，價值差最多的一項。**

會員人在外面，想知道「附近有沒有可以打折的店」——這件事網頁做不好，手機做得很好。

| 功能 | 說明 |
|---|---|
| **依距離排序** | 用手機定位算出直線距離，由近到遠排，直接顯示「距離 400 公尺」 |
| **地圖檢視** | 清單與地圖可切換，地圖上用類別圖示標出各店 |
| **一鍵導航** | 直接開啟手機地圖導航過去 |
| **一鍵撥號** | 直接撥打店家電話 |
| 分類與地區篩選 | 餐飲／運動用品／健康／教育／生活服務，加上地區 |
| 店家詳情 | 名稱、照片、地址、電話、營業時間、優惠內容、官網或社群連結 |
| 適用層級標示 | 「全會員適用」與「限付費會員」明顯區隔，後者對免費會員顯示升級提示 |

**關於定位權限，我們的做法**

1. **只在使用當下用定位，不做背景追蹤。**
2. 第一次用到時**先說明用途再要權限**，不是一開 App 就跳權限視窗。
3. 使用者拒絕授權時**功能不會中斷**——退回用地區手動篩選，也可以自己輸入地址查。
4. **位置座標不上傳、不儲存**，距離是在手機上算完就丟。

**要先處理的事**：目前特約店家的資料只有地址文字，**沒有經緯度座標**，沒有座標就無法算距離。後台會加上座標欄位與「由地址自動定位」的輔助按鈕，但**需要人工確認後儲存**。

### 3.4 會員中心與會籍

| 功能 | 說明 |
|---|---|
| 會員資料 | 姓名、手機、Email、生日、語言偏好；改密碼、刪除帳號 |
| 會籍狀態 | 層級、會員編號、有效期限、目前狀態（待確認／已開通／已到期） |
| **續會提醒** | 到期前 30 天在會員分頁顯示提示條，並發推播通知 |
| 球衣登記 | 尺寸、領取方式（寄送／到場領取）、收件資訊；狀態顯示「待處理／已寄出／已領取」 |
| 權益對照表 | 免費會員與付費會員的權益逐項對照，未登入也看得到 |
| 方案比較 | 費用、球季期間、可發幾張卡、幾件球衣、家庭方案 |

**App 內線上付費入會**：付費會籍可以在 App 裡用 **LINE Pay** 直接完成，付款成功後**系統自動開通會籍**，不用等人工確認。

這裡有兩條界線要先說清楚：

- **App 裡的付款只用在會籍費用。** 課程費維持線下繳費（匯款或現場收款）、商品在官網商店結帳、捐款走慈善平台。
- **App 不碰任何捐款金流。** 慈善單元最多提供外部連結，而且會明確標示收款方是台灣足球策略發展協會，不會讓人誤以為捐給俱樂部。

### 3.5 新聞與故事

| 功能 | 說明 |
|---|---|
| 分類瀏覽 | 沿用官網現有的八個分類，不另外新增 |
| 列表 | 封面圖、標題、分類、日期；下拉更新、往下滑自動載入 |
| 內文 | 中英文切換、可調字級、一鍵分享（分享出去的是官網網址，沒裝 App 的人也點得開） |
| **離線閱讀** | 開過的文章離線也能讀，保留 30 天 |
| 分類訂閱推播 | 可以只訂閱自己關心的分類 |

**新聞推播預設是關閉的**——文章的發布節奏若全部推播會造成打擾，由使用者自己開。

### 3.6 球隊與球員名單

| 功能 | 說明 |
|---|---|
| 各隊名單 | 依位置分組（守門員／後衛／中場／前鋒），組內依背號排序 |
| 球員卡 | 背號、中英文姓名、位置、照片 |
| 球員詳情 | 生日、身高體重、國籍、慣用腳、加入日期、前東家、經歷、本季數據（出賽、進球、助攻、黃紅牌）、相關新聞 |
| 教練與團隊 | 姓名、職稱、證照、專長、負責梯隊 |

**要先處理的事**：目前 28 名球員的照片與簡介都還沒有，素材到位後才會開啟這一節，而且**列表不會拿佔位圖充數**——寧可先只顯示背號與姓名的文字卡，也不放假圖。球員肖像同意書是否涵蓋 App 也需要先確認。

### 3.7 課程與營隊報名

**先釐清一件事**：官網本來就有線上報名，後台的報名管理也已經完整存在。**App 的報名不是新功能，是既有機制的手機版介面。**

真正新增的只有兩項，而且都是「會員對自己資料的操作」：

| 新增項目 | 說明 |
|---|---|
| **表單自動帶入** | 已登入的會員，姓名、手機、Email 自動填好，仍然可以改。手機上打字很痛苦，這一項在 App 的價值比網頁高一個量級 |
| **我的報名** | 列出自己報過的課程、梯次、時間、地點、繳費狀態 |

沿用官網、不會改動的規則：

- 報名狀態流程：待確認 → 已確認 → 已繳費 → 完成／取消／候補
- 梯次狀態：開放／額滿／候補／已結束，前台自動顯示「立即報名／額滿候補／已截止」
- **繳費維持線下作業**（匯款或現場收款後由後台標記）
- **非會員一樣可以報名**，不強迫先加入會員

**明確不做「學員家長綁定」**（官網、App、後台三邊都不做）。建立「成人 ↔ 未成年」的長期關聯，敏感度高一個等級；當初設計家庭會籍時就刻意避開了這個做法。學員資料仍然照舊存在報名紀錄裡，只是不建立家長與學員的綁定關係。

### 3.8 付費會員抽獎資訊（只顯示，不操作）

付費會員（球迷會員）擁有抽獎資格。App 在這裡的角色**只是讓會員知道自己有沒有資格**，不做任何抽獎操作。

**App 只顯示四件事**：

| # | 顯示內容 |
|---|---|
| 1 | **你的資格狀態**：「你的會籍在資格基準時間有效，將自動列入」或「會籍尚未涵蓋基準時間」 |
| 2 | 活動辦法、獎品內容與名額、注意事項（中英雙語） |
| 3 | 開獎時間與開獎場合（現場或直播） |
| 4 | 結果公布後，連往那一則最新消息 |

**刻意不做的部分**（與官網規則完全一致）：不顯示抽獎序號、沒有查詢介面、App 內不做中獎名單頁、沒有線上開獎動畫、沒有「目前多少人合格」的即時計數器、**不用推播做個別中獎通知**。

抽獎資格是**自動的、會員零操作**：基準時間會籍有效就自動列入，一人一號，**不會因為消費、簽到、分享或參加次數而增加機會**。實體開獎在現場或直播進行，結果只透過最新消息公布。

### 3.9 夥伴與贊助商

| 區塊 | 內容 |
|---|---|
| Our Partners | 依類型分區的 Logo 牆（策略／國際／訓練／教育／品牌），可看合作內容、期間、官網連結 |
| Our Sponsors | 依等級分區（主贊助／官方／支持），可連到贊助故事 |
| 洽詢 | 導向官網的合作與贊助洽詢表單 |

**贊助商 Logo 牆和廣告版位是兩件事**，這點很容易被混淆：

| | 贊助商 Logo 牆 | 廣告版位 |
|---|---|---|
| 位置 | 固定的夥伴專區與首頁下方 | 指定版位，多家輪播 |
| **計算曝光** | **不計** | 計算 |
| **進廣告報表** | **不進** | 進 |
| 標示「廣告」 | 不標 | **必須標** |

如果某家贊助商的合約裡包含「App 廣告版位若干檔期」，正確做法是替它另外建一筆廣告主資料、關聯回原本的贊助商紀錄，再開廣告檔期——這樣成效才會進廣告報表。**不會直接拿 Logo 牆的瀏覽數當成效**，那是對不出來的數字。

**素材紅線**：目前還沒有拿到任何夥伴或贊助商的名稱與 Logo。素材到位之前，**App 畫面與商店截圖一律不放示意用的假 Logo**——那等於對外宣稱一段不存在的商業關係。空缺處會以「合作洽詢中」的空格處理。

### 3.10 廣告版位（可以賣錢的部分）

App 提供**自售廣告版位**，賣給在地商家，成效由自家系統量測。

**版位位置**：首頁上方、首頁中段、賽程列表、新聞列表。

| 對球迷 | 對俱樂部與廣告主 |
|---|---|
| 每個版位都會**明顯標示「廣告」或「贊助內容」**，不會偽裝成編輯內容 | 後台可管理廣告主、投放檔期、輪播權重、每日曝光上限 |
| **不做開屏廣告**（一開 App 就擋住畫面的那種）、不做插頁廣告、不做影片前貼片、不做甩不掉的浮動廣告 | 提供曝光數、點擊數、點擊率、按日趨勢的報表，可匯出 CSV 與 PDF 給廣告主 |
| 版位高度固定，**不會因為廣告載入而讓畫面跳來跳去** | 曝光採業界通行標準認定（廣告區域一半以上連續看得到滿一秒才算一次） |
| 沒有廣告檔期時，版位顯示俱樂部自己的內容，**版位永遠不會開天窗** | 支援「曝光保證」型檔期，系統自動把保證量平均分配到整個檔期，不會前兩天燒完 |

**三個對廣告主其實是賣點的決定**

| 決定 | 好處 |
|---|---|
| **不接第三方廣告聯播網，只做自售** | 不用跳出「要不要允許追蹤」的討人厭視窗；App 可以誠實宣告「不追蹤使用者」 |
| **不使用廣告識別碼** | 不蒐集可以跨 App 追蹤個人的識別碼 |
| **不做行為定向** | 廣告只依「版位、語言、平台」決定，不看個人瀏覽紀錄 |

一句話給廣告主：**「我們的數字是自家系統直接量測的誠實數據，不是聯播網轉手的估算值。」**

**兩條限制**

1. **兒童會看的畫面不放廣告**：學院與課程相關畫面一律不設版位。這些畫面的受眾包含未成年，也與未成年學員的照片同框，不適合混入商業訊息。
2. **不刊登的類別**：菸酒、博弈、成人內容、醫療效能宣稱、金融投資招攬。廣告素材也不得使用俱樂部標誌或暗示官方背書（除非該廣告主確實是贊助商且合約載明）。發現違規時可立即下架單一檔期。

**第一版不做廣告主自助後台**——廣告主不用開帳號登入看報表，由業務匯出後寄送即可。

### 3.11 推播通知與通知中心

| 通知類型 | 什麼時候發 | 預設 |
|---|---|---|
| 賽事提醒 | 開賽前 2 小時 | 開 |

**App 內通知中心**：收得到的推播會留在 App 內的收件匣，保留 90 天，離線也能翻。

**使用者可以控制到什麼程度**

- 分類開關（賽事／賽果／新聞／會籍與球衣）各自可關
- 訂閱自己關心的球隊，賽事提醒只推那幾隊
- 每日免打擾時段（建議預設晚上 10 點到早上 8 點）
- 可以一鍵全部關掉——但**會籍到期提醒仍會用系統信送到**，重要通知不會只有推播一個管道

**三條界線**

1. **推播只依「會籍層級、訂閱球隊、語言」分眾**，不依瀏覽紀錄、點擊行為、所在位置或購買紀錄做個人化推播。
2. **推播絕不用於個別中獎通知**，系統信也維持原本的五封不變。
3. 官網那邊**維持不做**站內信與通知中心——這個通知中心只存在於 App 內。

### 3.12 設定與帳號

語言切換、推播權限與分類、定位權限說明、清除快取、離線內容管理、隱私政策、服務條款、「為什麼我會看到廣告」說明頁、版本資訊與更新檢查、聯絡我們、登出、**刪除帳號**。

**刪除帳號必須能在 App 內直接完成**（這是 Apple 與 Google 商店的強制規定），不能只寫「請來信申請」。刪除後會員個資會清除，已鎖定的抽獎名單只保留會員編號與遮罩後的姓名。

### 5.1 沒有它就做不了（優先處理）

| # | 事項 | 沒有的話會怎樣 |
|---|---|---|
| 1 | **App 商店對「付費會籍」的認定**：付費入會能不能走 LINE Pay，而不是走 Apple／Google 的內購？（因為會籍權益以實體為主——球衣、店家折扣、現場活動——有主張空間，但最終是商店的審查判斷） | **這是上架最大的單一風險。**需要同時準備替代方案 |
